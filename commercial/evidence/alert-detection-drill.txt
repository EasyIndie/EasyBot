RECOVERY
--------

the alert cleared.

RESULT: PASS (detection + alert firing validated end-to-end)

FINDING (operational)
---------------------
Writing to a live database file from outside the running app breaks the app's
open connection pool ("file is not a database", SQLITE_NOTADB) because the
WAL/lock state is not coordinated across the host/container boundary on Docker
Desktop. Production guidance: never write to the DB directly; use the app or
the paired backup/restore tooling. This drill uses stop -> edit -> start.

BLOCKER (delivery)
------------------
Alert FIRING was validated in Prometheus. Delivery to a human operator
(Alertmanager -> email/webhook/paging) requires an Alertmanager + receiver
configuration, which is a G1 infrastructure task not executable from the repo.
