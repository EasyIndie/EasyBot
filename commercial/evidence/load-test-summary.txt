NOTE ON RATE LIMITING
---------------------
The production per-IP rate limiter defaults to 60 requests/min. A 500-request
load from a single IP at that default produced HTTP 429 (error_rate ~4.6%),
which CONFIRMS the production rate limiter engages correctly. The G0 baseline
and this measurement therefore use a raised per-IP limit (12000/min, burst
200) so the test measures CPU/memory-bound throughput rather than the
per-IP limiter. The Managed Pilot SKU promises 600 requests/min/customer as a
quota cap, not concurrent throughput; the per-IP limiter should be sized per
deployment for G1.
